# Krugersdorp Painters — Next.js 15

This folder is a **Next.js 15 (App Router)** port of the static HTML site in the parent directory.

## How it works (phase 1)

- Page **markup** is read from `content/html/*.html` at build time. The `<body>` inner HTML is injected (without `<script>` tags) via `LegacyPage`.
- **Styles** and **scripts** are served from `public/css` and `public/js` (copied from the legacy project).
- `LegacyScriptLoader` loads the same script chain as the original site (jQuery, Bootstrap, Swiper, WOW, `function.js`, etc.).
- Internal links in the HTML are rewritten from `*.html` to **App Router paths** (`/about`, `/services`, …).

## Performance & SEO

- **Preloader** is stripped from HTML at render time and removed from `public/js/function.js` (better LCP / Lighthouse).
- **Fonts**: `next/font` (DM Sans + Space Grotesk) with `display: swap` — no render-blocking Google Fonts CSS link.
- **CSS**: `animate.css`, `magnific-popup.css`, and `mousecursor.css` load **after first paint** via `DeferredStyles`.
- **JS**: jQuery, Bootstrap, SlickNav, Swiper, Waypoints, and CounterUp load first; Isotope, Magnific, SmoothScroll, Parallaxie, GSAP, SplitText, ScrollTrigger, WOW, and `function.js` load on **`requestIdleCallback`** (with timeout). **magiccursor.js** is omitted.
- **Caching**: long-cache headers for `/js/*` and `/css/*` in `next.config.ts`.
- **SEO**: each route exports `metadata` from `src/config/seo.ts` (title, description, keywords, canonical, Open Graph, Twitter, robots). **JSON-LD** includes `HomeAndConstructionBusiness`, `WebSite`, `WebPage`, `BreadcrumbList`, plus `ContactPage` on `/contact`, `FAQPage` on `/faqs`, and `ItemList` on `/services`.
- **Production domain:** `https://krugersdorppainting.co.za` is the default canonical base in code. For staging, set **`NEXT_PUBLIC_SITE_URL`** on the host (no trailing slash).
- **Google Search Console:** after deploy, add the property for `krugersdorppainting.co.za`, verify (HTML tag or DNS), then submit **`/sitemap.xml`** (generated by `src/app/sitemap.ts`). Optional: set **`NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`** in `.env` / Vercel so the meta tag is emitted from `layout.tsx`.

## Commands

```bash
cd next-site
npm install
npm run dev
npm run build
npm start
```

## Updating content

1. Edit the HTML in `content/html/` (or copy updated files from the parent repo).
2. Re-run `npm run build`.
